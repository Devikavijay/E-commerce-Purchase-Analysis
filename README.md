# E-Commerce Purchase Data Analysis

### Project Overview

This project analyzes an E-commerce purchase dataset to uncover customer buying behavior, sales patterns, and key factors that influence purchases. Using Python, Pandas, and visualization libraries, the analysis reveals trends in product categories, customer spending, and seasonal behavior to derive actionable business insights.

#### Dataset Description

The dataset includes real-world e-commerce purchase records featuring:

Order IDs

Customer IDs

Product categories

Purchase amounts

Purchase timestamps

Customer demographics

The objective is to explore patterns, distributions, and relationships among variables to understand purchase dynamics and customer behavior.

#### Exploratory Data Analysis (EDA)

The analysis includes:

Understanding the dataset shape, structure, and summary statistics

Detecting and handling missing values

Exploring purchase distributions over time (year/month/day)

Identifying top-selling categories and high-revenue products


This helps highlight trends such as peak purchase periods, popular categories, and customer spending behavior.

#### Key Insights

The EDA supports findings such as:

Seasonal purchase trends (e.g., peak months or days)

Customer segments that spend more

Product categories with the highest sales and order counts

Correlations between variables indicating buying behavior

These insights illustrate how data can guide sales and marketing strategies.
